# /promo-status — 노션 대시보드 현황 조회 (생성 작업 없음)

노션 프로모션 대시보드 DB의 현재 상태를 빠르게 조회한다. **HERO/CONTENT 생성 등 작업은 일절 수행하지 않는다.** 단순 조회 전용.

---

## STEP 0: 환경 초기화

`/promo-run` STEP 0과 동일하게 설정값 확인 → GitHub에서 파일 다운로드 (덮어쓰기) → 완료 후 진행.

---

## STEP 1: DB의 모든 row 식별

`notion-search` 호출 (`notion-query-data-sources`는 환경에 따라 미존재 — `notion-search`로 대체):

```
mcp__...__notion-search
  query: "프로모션"
  data_source_url: "collection://${NOTION_DB_ID}"
  filters: {}
  page_size: 25
```

> **Note**: `notion-search`는 시멘틱 검색이라 모든 row가 한 번에 반환된다는 보장 없음. 누락 가능성 줄이려면 추가 쿼리 (`"이벤트"`, `"업데이트"`, 노션 DB의 게임명 select 옵션 등) 시도 후 `url` 기준 중복 제거.

검색 결과는 row 페이지의 `id`, `title`, `url`만 반환. 상세 properties는 다음 STEP에서 fetch.

전체 row가 0건이면 "DB가 비어있습니다." 출력 후 종료.

---

## STEP 2: 각 row의 properties fetch (병렬)

검색 결과 각 페이지에 대해 `notion-fetch` 호출. **단일 메시지에 모든 fetch 동시 호출 (병렬)**.

```
mcp__...__notion-fetch  id: <row URL 또는 id>
```

각 fetch에서 다음 properties 추출:
- 프로모션명 (title)
- 게임명 (select)
- 담당자 (people)
- 상태 (select)
- HERO 컨펌 / CONTENT 컨펌 / 테스트 배포 / 라이브 배포 (checkbox: `__YES__` / `__NO__` / NULL)
- 라이브 날짜 (date)
- 비고 (text, 실패 사유 등)

---

## STEP 3: 클라이언트 사이드 필터링 + 그룹핑

각 row를 다음 카테고리로 분류:

- **⏳ 대기** (상태 = ⏳대기) → 다음 단계: HERO 생성
- **🎨 HERO 생성 중** (상태 = 🎨HERO생성)
- **⚠️ HERO 컨펌 대기** (상태 = ⚠️HERO컨펌대기, HERO 컨펌 = false)
  - 이 중 컨펌된 것 (HERO 컨펌 = true) → 다음 단계: CONTENT 생성
- **📝 CONTENT 생성 중** (상태 = 📝CONTENT생성)
- **⚠️ CONTENT 컨펌 대기** (상태 = ⚠️CONTENT컨펌대기, CONTENT 컨펌 = false)
  - 이 중 컨펌된 것 (CONTENT 컨펌 = true) → 다음 단계: 결과물 저장
- **✅ 생성 완료** (상태 = ✅생성완료)
  - 이 중 테스트 배포 = true → 다음 단계: 테스트 서버 업로드
- **🧪 테스트 배포** (상태 = 🧪테스트배포)
  - 이 중 라이브 배포 = true → 다음 단계: 라이브 서버 업로드
- **🚀 라이브** (상태 = 🚀라이브) — 완료
- **❌ 실패** (상태 = ❌실패)

---

## STEP 4: 결과 출력

다음 형식으로 표시:

```
📊 노션 대시보드 현황
조회 시각: <YYYY-MM-DD HH:MM>
전체 row: N건

────────────────────────────────────────
▶ 진행 가능한 작업 (다음 /promo-run 시 실행)
────────────────────────────────────────
[HERO 생성 대상] N건
  - <프로모션명> (<게임명>)
[CONTENT 생성 대상 — HERO 컨펌됨] N건
  - <프로모션명> (<게임명>)
[저장 대상 — CONTENT 컨펌됨] N건
  - <프로모션명> (<게임명>)
[테스트 배포 대상] N건
  - <프로모션명> (<게임명>)
[라이브 배포 대상] N건
  - <프로모션명> (<게임명>)

────────────────────────────────────────
⏸ 사용자 액션 대기 (컨펌 체크박스 미완료)
────────────────────────────────────────
[HERO 컨펌 대기] N건
  - <프로모션명> (<게임명>) — 라이브 날짜: YYYY-MM-DD
[CONTENT 컨펌 대기] N건
  - <프로모션명> (<게임명>)

────────────────────────────────────────
✅ 완료 / ❌ 실패
────────────────────────────────────────
[라이브] N건
[실패] N건
  - <프로모션명> (<게임명>) — 비고: <비고>
```

---

## STEP 5: 다음 액션 안내

진행 가능한 작업이 있으면:
```
▶ 다음 단계 실행: /promo-run
```

사용자 액션 대기가 있으면:
```
⏸ 노션에서 컨펌 체크박스를 확인해주세요. 컨펌 후 /promo-run 실행
```

모두 라이브 상태면:
```
🎉 모든 작업 완료. 새 row 추가 후 /promo-run
```

---

## 주의

- 이 커맨드는 **읽기 전용**. notion-update-page 호출 금지.
- 이미지 생성, HTML 작성 등 작업 일절 수행하지 않음.
- `/promo-run` 사용 전 현황 파악 용도.
- `notion-search`가 시멘틱 검색이라 row 누락 가능성 있음. 누락 의심 시 다양한 쿼리로 재실행.
