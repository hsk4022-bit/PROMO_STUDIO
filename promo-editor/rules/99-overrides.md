## 사용 규칙

1. 이 파일은 **누적**이지 덮어쓰기 아님. 기존 줄 삭제하지 말 것 (사용자가 명시 철회 요청한 경우만).
2. 한 항목에 대한 새 교정이 들어오면 기존 줄 아래에 `→ 갱신:` 로 추가. 옛 줄도 남김 (히스토리).
3. 항목이 모호하면 작업 전에 사용자에게 1회 확인.
4. 위 룰 01~20 과 충돌 시 이 파일 승.
5. 팀이 공유하므로 **개인 취향 (예: 단축키, 폴더 배치)** 은 여기 말고 Claude memory 에.
