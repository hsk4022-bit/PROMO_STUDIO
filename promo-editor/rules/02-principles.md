# [제0원칙 — 원고 텍스트 절대 우선]
- 원고의 모든 문장·단어·숫자·특수문자를 단 한 글자도 바꾸지 말고 그대로 출력.
- 요약·압축·윤문·재해석 절대 금지. 원고에 10줄이면 HTML에도 10줄.
- **AI 임의 생성 금지 범위 (전체 결과물 해당)**:
  - 본문 임의 문장·설명·부연 추가 금지
  - 팝업 제목·라벨·헤더·설명 임의 생성 금지
  - 버튼·메뉴·푸터·저작권·영문 부제목·슬로건 임의 생성 금지
  - AI 생성 영문 텍스트("Game Title", "Special Event" 등) 삽입 즉시 FAIL
  - 임의 이미지 플레이스홀더 생성 금지
- placeholder 절대 금지. 마지막 문장 누락 여부 반드시 확인.
- **원고 누락 검증 필수**: 작업 완료 후 반드시 원고 라인 수와 HTML 내 대응 요소 수를 비교하여 누락 여부 확인.

# [제0.5원칙 — 구조 우선 (Structure-first)]
- **원고 전체를 먼저 파악**한 뒤, 섹션·계층·카드 묶음 구조를 먼저 확정하고, 그 후 HTML 한 줄을 쓴다.
- 한 섹션씩 쓰면서 구조를 바꾸는 **iterative patching 금지**. 섹션 A 완성 → 섹션 B 보다가 "A도 다시 나누자" 식 반복 시 FAIL.
- **구조 확정 체크리스트**:
  1. 같은 depth 형제 섹션이 무엇인가? (예: "이벤트 기간" vs "이벤트 내용" 은 형제)
  2. 자식 블록이 무엇인가? (예: 탭 바 + 개별 이벤트 1~8 은 "이벤트 내용" 의 자식)
  3. 각 섹션 내부에 시각적으로 분리가 필요한 서브 블록이 있는가? (→ 중첩 카드 사용 근거)
  4. 카드 묶음 단위는? (하나의 대카드 + divider 인가 / 각 섹션별 독립 카드 인가)
- 위 4항목을 **Checkpoint 1 단계에서 사용자에게 공유**한 뒤 승인 받고 HTML 생성 시작.
