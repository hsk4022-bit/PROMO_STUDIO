# [컬러 시스템]

> ⚠️ **PALETTE PRE-ENFORCED**: 아래 색 변수들은 시스템이 사전 검증 통과시킨 값이다. AI 는 받은 색을 그대로 사용. 임의 보정·블렌딩·다른 색 추가 절대 금지. 변수 역할 고정 (${accentColor}=포인트, ${textColor}=본문, ${bgColor}=2번 블록 배경, ${surfaceColor}=카드 배경, ${borderColor}=라인). 역할 바꿔 쓰면 FAIL.
>
> 시스템이 보장하는 속성:
> - **bg**: 라이트 L 0.92~0.96 또는 다크 L 0.05~0.18. **채도 S 0.30~0.55** (자신 있는 warm/cool pastel — near-neutral 회백색 아님).
> - **surface**: bg 보다 elevation 방향 (라이트=L 0.97, 다크=L 0.24~0.28). S 0.20~0.40.
> - **accent**: S ≥ 0.65 (활기 있는 포인트), L 0.38~0.55 (라이트) / 0.50~0.68 (다크).
> - **text**: L ≤ 0.10 (라이트) / ≥ 0.96 (다크) — bg hue hint 살짝.
> - **border**: L 0.70~0.78 (라이트) / 0.38~0.42 (다크), bg hue family 유지.
> - **muddy zone(L 0.40~0.80 + S<0.30) 진입 불가** — 사전에 차단됨.

> ⚠️ **히어로 톤 반영 (필수 · 위반 시 FAIL)**: ${bgColor} / ${surfaceColor} 의 hue 는 **히어로 이미지의 dominant warm/cool mood 와 동일 hue family** 여야 함.
> - 히어로가 따뜻한 톤(카페·자연·파스텔·일러스트의 브라운/크림/핑크/오렌지 계열)이면 bgColor 도 따뜻한 다크 (예: warm cafe → `#2c1d14` 다크 브라운, `#3a2418` 카카오) 또는 따뜻한 라이트 (`#fff5e6` 크림).
> - 히어로가 차가운 톤(블루·민트·보라)이면 bgColor 도 차가운 다크/라이트.
> - ❌ 금지: 히어로가 warm 카페 분위기인데 bgColor 가 `#110909` 같은 거의 순흑 (hue ≈ 0, S ≤ 35, L ≤ 6) — 히어로와 본문이 시각적으로 단절되어 "AI 가 컬러를 안 골랐다" 인상을 줌. **즉시 FAIL**.
> - 다크 테마여도 반드시 히어로 hue 의 다크 버전 사용. 순흑/순백 fallback 금지.

- 60:30:10 법칙: 배경(60%) ${bgColor} / 서피스(30%) ${surfaceColor} / 포인트(10%) ${accentColor}.
- 카드·컨테이너 구분: 배경색 명도 3~5% 조절한 hex 또는 1px border만 사용.
- 포인트색 ${accentColor}: 번호아이콘·CTA버튼·핵심키워드에만 한정.
- 모든 텍스트 요소(p span td th h1~h6 등)에 color 속성 반드시 명시.
- ${textColor} 기본 텍스트 / ${subColor} 서브 / ${accentColor} 강조 / ${surfaceColor} 카드배경 / ${borderColor} 테두리 / ${mutedColor} 부가정보 카드.

## ⚠️ 카드 bg 선택 기준 — 콘텐츠 비중에 따라 (위반 시 FAIL)
- **메인 콘텐츠** (이벤트 내용·보상·참여방법) → ${surfaceColor} (bg 보다 elevation, 시각적 강조)
- **핵심 강조** (CTA·핵심 보상 강조) → accent+bg 혼합 틴트
- **유의사항·주의사항·참고·안내·면책·하단 부가정보** → 반드시 ${mutedColor} (bg < muted < surface 위계 — bg 보다 살짝 밝지만 surface 만큼 elevated 되지는 않음). surfaceColor 로 감싸면 부가정보가 본문보다 도드라져 시각 위계 역전 → FAIL.

## 가독성 대비 규칙 (WCAG 최소 기준 — 위반 시 FAIL)
- **텍스트와 배경의 명도 대비가 충분하지 않으면 FAIL.**
- 어두운 배경(${bgColor} 명도 < 40%)일 때:
  - ${textColor}는 반드시 밝은 색 (명도 70% 이상). 예: #e2e8f0, #f0e6e6
  - ${subColor}는 중간 밝기 (명도 50~70%). 예: #94a3b8, #a0aec0
  - ${accentColor}는 채도 높고 밝은 톤 사용 (어두운 배경에서 눈에 띄어야 함)
  - 섹션 제목에 ${accentColor} 사용 시, 해당 색이 ${surfaceColor} 위에서 충분히 대비되는지 확인
- 밝은 배경(${bgColor} 명도 > 60%)일 때:
  - ${textColor}는 반드시 어두운 색 (명도 30% 이하). 예: #1e293b, #2d2d2d
  - ${accentColor}는 채도 높고 어두운 톤 사용
- **테이블 th**: 배경색과 텍스트 색의 대비 반드시 확인. th 배경이 어두우면 텍스트는 밝게, th 배경이 밝으면 텍스트는 어둡게.
- **번호 아이콘(원형 배지)**: 배경 ${accentColor}와 텍스트 색의 대비 확인. 어두운 accent면 color:#ffffff, 밝은 accent면 color:#000000.

## 칙칙한 컬러 방지 규칙 (위반 시 FAIL)

**"진흙색 존(muddy zone)" 팔레트 절대 금지.** 전체 페이지가 탁하고 답답하게 보이는 원인. HSL 기준으로 판정.

### 개별 색상 제약
- **${accentColor}**: 채도 S ≥ 50 필수. 저채도 갈색·카키·회색 계열 절대 금지. (S < 50 이면 강조 기능 상실 → FAIL)
- **${bgColor}**: 명도 L 범위 — 밝은 테마는 L ≥ 88, 어두운 테마는 L ≤ 20. **중간 명도(L 40~80) 금지.** 중간 명도 + 저채도 조합이 가장 탁한 "진흙색" 영역.
- **${surfaceColor}**: ${bgColor} 대비 명도 차이 **최소 ±5, 최대 ±12**.
  - ±5 미만: 구분 안 됨 → 섹션 경계 불명확
  - ±12 초과: 계단처럼 대비 과해서 피로감
- **${borderColor}**: ${surfaceColor} 와 명도 차이 **최소 ±10, 최대 ±20**.
  - **±10 미만 절대 금지** → 테이블 행 구분선·셀 보더가 안 보임. 표가 "떠 있는 박스"처럼 시각 붕괴 → **즉시 FAIL** (라이트 베이지/크림 테마 빈번).
  - **±20 초과 절대 금지** → 라인이 너무 진해 페이지가 격자 무늬처럼 무거워짐. 데이터보다 선이 먼저 보임 → **즉시 FAIL** (다크 네이비/딥 테마 빈번).
  - **권장 범위 ±12~±18**: 보더가 "있는 줄 알게" 보이되, 시선을 뺏지 않는 수준.
  - **라이트 테마**(surface L ≥ 85): borderColor 는 **L 70~78 권장** (surface 와 차이 7~18).
  - **다크 테마**(surface L ≤ 25): borderColor 는 **L 38~45 권장** (surface 와 차이 13~20). L 50 초과 절대 금지.
  - ${bgColor} 와의 차이도 동일 기준 (테이블이 bgColor 위에 놓이는 경우 대응).

### 팔레트 전체 제약
- **모든 색(bg/surface/text/accent/border)이 채도 S < 30 범위에 몰리면 FAIL.** 최소 하나(반드시 accent)는 S ≥ 50 고채도 필수.
- **모든 색이 동일 색상계(예: 베이지·브라운만, 카키·올리브만) 안에 있으면 FAIL.** accent 는 반드시 다른 색상계 (보색·유사색·중성 강조).
- **채도 차이 전략**: 대비는 명도뿐 아니라 **채도**로도 확보. 배경은 저채도(S 10~30), accent 는 고채도(S ≥ 50) — 이 대비가 없으면 전체가 탁함.

### 교차 배경 사용 시 (섹션 alternating)
- 두 배경색 명도 차이 **5~10 권장**. 10 초과 시 줄무늬 착시. 5 미만 시 효과 없음.
- 두 배경색이 모두 저채도(S < 20) + 중간 명도(L 60~80) 조합이면 **둘 다 탁해 보임 → FAIL**. 적어도 한쪽은 밝게(L > 90) 끌어올리기.

### 금지 팔레트 예시
- ❌ `#dcbdb6 + #eac9c2 + #694612 + #c9ada7` — 전체 베이지·브라운계, 채도 낮고 명도 중간, 탁함 전형
- ❌ `#8b7355 + #a69b8d + #6b5d4f` — 모든 색이 카키·브라운, 구분 불가
- ✅ `#ffffff + #f5f5f5 + #0f0f0f + #3264ff` — 저채도 배경 + 고채도 포인트, 명도 극단 대비
- ✅ `#fff5e6 + #ffe4bc + #2d2d2d + #e63946` — 따뜻한 크림 배경 + 빨간 포인트, 크리스마스 테마에 적합
