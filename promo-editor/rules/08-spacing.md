# [간격 처리 규칙 — 단일 기준]
- 요소 사이 간격: 반드시 <p style="height:Npx;margin:0;"></p> 태그로만 처리.
  - 극소: height:8px / 소: height:16px / 중: height:32px / 대: height:48px / 특대: height:64px
- margin 사용 금지. <br> 단독 사용 금지. <p>&nbsp;</p> 금지.
- 모든 <p> 태그: margin:0; line-height:1.8;

## ⚠️ 간격 트리거-액션 매핑 (위반 시 FAIL)

| 트리거 | 강제 간격 |
|---|---|
| 섹션 카드 → 다음 섹션 카드 | 소 16px ~ 중 24~32px (너무 멀면 흐름 끊김) |
| 섹션 타이틀 → 본문 시작 | 중 32px |
| 소제목(■ ▶) → 다음 콘텐츠 | 중 32px |
| 이전 콘텐츠 → 다음 소제목 | 대 48px (위로 호흡 더 크게) |
| 테이블 → 캡션("*~", "※~") | 소 16px |
| 캡션 → 다음 소제목/콘텐츠 | 대 48px |
| 테이블 → 다음 테이블 | 중 32px |
| 텍스트 단락 → 다음 텍스트 단락 | 소 16px |
| 본문 → 다음 테이블 | 중 32px |
| 테이블 → 다음 본문 | 중 32px |

**핵심 원칙:**
- 같은 그룹 내(헤더-내용 / 테이블-캡션) = 좁게 (16~32px)
- 다른 그룹 사이(소제목 위 / 섹션 사이) = 시원하게 (48~64px)
- 의심 시 더 크게 — 답답한 것보다 시원한 게 낫다

## ⚠️ 대제목 자동 승격 금지
- 원고 첫 문장이 "~안내드립니다", "~기념하여...", "~감사드립니다" 같은 마침표로 끝나는 서술형 문장이면 본문 처리. 절대 font-size 1.25rem+ 로 키우지 말 것. 위반 시 FAIL.
- 대제목 허용 조건: 짧은 명사구가 단독 라인으로 등장 + 마침표 없음. 문장 형태이면 본문.

## ⚠️ 수치·날짜 강조 신중 사용
- "수치·날짜 강조" (clamp(1.5rem,3vw,2rem)) 는 단독 강조 박스 내 핵심 보상 수량 등 1-2 단어 숫자에만 사용.
- 긴 날짜 범위 문장("2025년 12월 24일 ~ 2026년 1월 22일")은 본문 사이즈로 표시. 1.5rem+ 적용 시 FAIL.
